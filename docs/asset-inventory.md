# Asset inventory

## Planned asset categories

1. Environment art
   - terrain blockouts
   - foliage placeholders
   - decorative props
2. Character art
   - humanoid or creature base meshes and materials
   - animation rigs
3. UI art
   - HUD elements
   - button states
   - splash and iconography
4. Audio
   - music and SFX placeholders
   - source recordings with license documentation
5. VFX
   - particle effects
   - environment ambience effects

## Current status

The repository currently contains only the project foundation and original author-created placeholder art assets required for engine validation.

## Policy

- Any future 3D asset imported into Godot must be reviewed for provenance and license compatibility.
- No unlicensed asset or purchased asset pack is permitted without explicit ownership review.
- Each asset should be entered into the licensing register before integration.
